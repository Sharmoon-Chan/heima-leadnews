## 4. 对四项问题的决定

1. **当前数字只作首份观测。** P1.3 后固定缓存方案做至少三轮 AB/BA 缓存专项对照；P4 再按最终组合配置复测。当前百分比不进简历。
2. **接受保留普通配置开关，不搬 Profile 装配。** 它默认 true、没有新增端点，false 仍执行同权限/同契约的直查路径，便于对照和回退。原卡“仅测试 profile”在代码中并无硬限制；负责人明确接受该项实现偏差，实验使用范围仍限定 p1 启动配置，不再写成“其他 profile 无法关闭”。本次不加结构拆分或改代码。
3. **ArticleDetailVo 保留 model/article/vos。** 与已有 VO 组织一致，没有必要为迁移位置增加重跑和跨模块改动。接受此位置不代表后续新增字段可忽略 API 契约。
4. **事务放 P1.3。** P1.1 只验证正常/空值缓存、TTL、补录失效与写路径，不顺手调锁或拆事务。

保留独立测试库和 p1 profile 以便下一阶段复跑，不覆盖课程配置；数据/配置变化须生成新标识。课程库仍 26 篇属于执行者的收尾声明，本次没有再次连接数据库确认。
