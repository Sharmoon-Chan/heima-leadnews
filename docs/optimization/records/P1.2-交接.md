## 3. 实验边界（读结论前必看）

- 单机闭环：一个 16 逻辑核宿主机上，2 个本机 JVM + 本机 MySQL/Redis，**不是集群**，不构成容量结论。
- 模拟而非真实故障：慢 DB（回源前睡眠）、Redis 读/争锁/释放异常、等待中断、持锁超租期，全部由探针按 articleId/stage 注入，**默认关闭**；Windows Redis/MySQL 服务没有被停止或重配。C4 是真实进程终止（自建实例，已校验进程名）。

- 回源数是 **DAO 进入次数**（`db.enter`），不是物理 SQL 条数；本轮没有做逐请求 SQL 归属。

## 5. 参数与取舍

| 参数 | 取值 | 依据 / 为什么不用别的 |
|---|---|---|
| 租期 `lock.expire-millis` | 3000（原值） | 卡面要求先把 3000 当对照；本轮不做调优。更短租期只用于「持锁超租期」功能试验 |
| 等待预算 `wait-budget-millis` | 1000 | 修前实测正常回源 4–10 ms；C2 的慢回源注入 300 ms。1000 ms 能覆盖「一次慢重建 + 余量」，同时 < 租期 1/3，不会把租期变成等待上限。候选 200 ms 单独跑过（§4），用于验证「预算不足必须显式失败而不是全体回源」 |
| 退避 `wait-backoff-millis` / `-max` | 10 / 50 | 冷突发里 30 个等待者在 1000 ms 内重试 45 次（预算 200 ms 样本），指数退避 + ≤50% 抖动避免同一瞬间反复争抢；上限 50 ms 保证预算内还有多次重试 |
| 失败策略 | 显式 503 + 结构化分类 | 卡面指定的保库策略：不允许等待者退化成无锁回源 |

选择顺序是「先测再定」：修前先记录原租期与正常回源耗时（4–10 ms），再冻结候选（200 / 1000），最后用 C2 两种预算各跑一次说明取舍。

## 7. 中断策略偏离及负责人限定裁定

负责人裁定：接受当前唯一 HTTP 调用方的终止路径消费中断并返回明确 503，不要求机械恢复造成断流的路径。InterruptedException 自带标记清除语义，catch 中 Thread.interrupted() 的 false 不能作为“观测到中断”的证据；改记捕获事实并保留传播边界。下文为执行者当时说明，不能推广到所有线程/通用任务服务。

卡面写「线程中断恢复中断标记并终止等待」。本轮实现是**清除**标记而不是重新置位，理由是可复现的实测：
把标记留给容器后，Tomcat 写响应时抛 `ClosedByInterruptException`（`SocketWrapperBase.doWrite`，原始栈在
`logs/fixed/fixed-main-r01.log`），客户端收不到响应体，C6 首轮 `C6-POST-r02` 就是这样失败的。
现在中断事实被记录成 `wait.end outcome=interrupted` + `FAIL_INTERRUPTED`，并返回明确的 503，
不构成「吞掉中断信号」。如果负责人要求严格重置标记，需要接受「该请求的响应可能写不出去」。

### 11.2 R2 异常注入走实际 I/O 的 try 边界

新增 `redisIo(stage, reqId, id, Supplier)` 作为**详情读路径上所有 Redis I/O 的唯一入口**（口径修正：写入路径的 `setEx`、`delete` 以及 `evictArticleDetailCache` 的删除**不**走它，所以不能说「全服务所有 Redis I/O 唯一入口」）：`io.begin` → 注入点 → 真实调用 → `io.end`（含 elapsedMs）都在同一个 `try` 内，`catch (RuntimeException)` 先写 `io.error stage=… elapsedMs=… error=<异常类>` 再原样抛出。因此「注入的故障」和「真实故障」走同一分支，分类可逐条核对，不再依赖全局兜底返回的 503。

| 阶段 | 修前 | 修后 |
|---|---|---|
| 首读 `read` | 异常冒到全局 → 503，但无阶段分类 | `FAIL_REDIS_ERROR_READ` + `io.error stage=read`，无锁、无回源 |
| 争锁 `lock` | 同上，且无法区分是争锁失败还是读失败 | `FAIL_REDIS_ERROR_LOCK` + `io.error stage=lock` |
| 双重检查 `recheck_after_lock` | 异常冒到 finally 前，风险是不确定状态 | 明确失败并释放自己的锁（`io.error` 已记分类） |
