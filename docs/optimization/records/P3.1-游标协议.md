# P3.1游标协议

新增`POST /api/v1/article/search/cursor`，保留旧`/search`及UserSearchDto不变。请求`searchWords`必填1–200字符、pageSize默认10且范围1–50、cursor首屏不传；可选upperBoundMillis只定义首屏上界（正值且不晚于服务器当前时间），后续若重复传必须等于cursor内边界。

ResponseResult.data包含items、hasMore、nextCursor、upperBoundMillis、tookMs。排序固定publishTime DESC + id DESC，id映射long/doc_values；排除缺publishTime/id记录。items.id返回精确十进制字符串。末页/无结果hasMore=false且nextCursor=null。

cursor为长度不超过2048的Base64URL JSON，字段v=1、q=关键词与排序指纹、sort、upper、time、id（字符串）。后端严格检查版本、类型、Long范围、时间边界及查询一致性。它是连续翻页状态，不是鉴权凭据，也没有承诺防篡改签名；请求仍按服务本身访问规则处理。

首屏固定时间上界，续页使用完整实际返回排序元组。请求size+1判hasMore，但cursor取最后一条返回记录，不能取额外探测记录。允许中途更改pageSize，不能更改关键词/排序/已固定上界。无效协议参数返回业务501，非法查询语法按ES400归入参数错误。

匿名请求不写Mongo历史；登录用户仅首屏按既有异步history路径记录。实验各组均匿名，不能将关闭历史的差异当作优化收益。标题片段不存在时h_title回退原title。

部署ES7.4.0，无PIT。固定上界只能挡住晚于首屏边界的新增文档，不提供快照：删除未读文档会减少结果，旧时间插入可能新增结果，已返回文档被改到更早时间可能再次返回。测试已观察这些边界，不宣称动态索引总能无重无漏。
