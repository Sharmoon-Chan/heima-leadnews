## 3. 数据准备

仓库内**没有**课程原始建表 SQL，`benchmarks/data/p0-schema.sql` 是按实体注解与
`ApArticleMapper.xml` 反推的**最小重建 schema**（只含 `ap_article`、`ap_article_content`、
`ap_article_config`），不是课程/生产原始 DDL。

```powershell
# 1) 生成 1 万篇合成文章（固定种子，确定性；脚本为 ASCII，避免 PS 5.1 按 GBK 解析中文）
powershell -NoProfile -ExecutionPolicy Bypass -File benchmarks/data/generate-p0-data.ps1 `
  -OutDir D:/Code/Java/heima-leadnews/_optimization-artifacts/20261028-P0-DATA

# 2) 建表 + 导入（注意：必须用 cmd 重定向，Get-Content -Raw 会按 ANSI 解码导致中文乱码报语法错误）
cmd /c "docker exec -i leadnews-p0-mysql mysql -uroot -p<密码> --default-character-set=utf8mb4 leadnews < D:\Code\Java\heima-leadnews\heima-leadnews\benchmarks\data\p0-schema.sql"
cmd /c "docker exec -i leadnews-p0-mysql mysql -uroot -p<密码> --default-character-set=utf8mb4 leadnews < D:\Code\Java\heima-leadnews\_optimization-artifacts\20261028-P0-DATA\p0-data.sql"

# 3) 校验
docker exec leadnews-p0-mysql mysql -uroot -p<密码> leadnews -e "select count(*) from ap_article; select count(*) from ap_article_content;"
```

本轮实测：`ap_article` 10000 行（1000001..1010000）、`ap_article_content` 10000 行、
`ap_article_config` 10000 行；`p0-data.sql` SHA256 `f7b4d25eac80871f9d95f1a469ae67c3a297280031855a5f240b9b79d6f80f01`，
重跑一次生成到另一目录，哈希一致（确定性已验证）。
不存在 ID 集 `2000001..2000100` 不落库，专门用于空值缓存实验。

## 5. 启动 article（本地最小链路）

配置示例：[article-p0-local.yml.example](../../../benchmarks/config/article-p0-local.yml.example)；
真实副本（含密码）在仓库外：`D:/Code/Java/heima-leadnews/_optimization-artifacts/local-secrets/article-p0.yml`。

两个必须注意的运行时事实（本轮实测得出，未改动任何业务代码）：

1. **Nacos 必须显式关闭**：`--spring.cloud.nacos.config.enabled=false --spring.cloud.nacos.discovery.enabled=false`，
   否则启动阶段会因为配置中心不可达而阻塞/失败。
2. **classpath 上的 logback 必须排除**：`freemarker-starter` 带进 `logback-classic`，而根 POM 用 `log4j2`。
   两者同时存在时启动直接抛
   `IllegalArgumentException: LoggerFactory is not a Logback LoggerContext but Logback is on the classpath`。
   本轮的处理方式是**在本地运行目录删掉 logback 的两个 jar**，没有改 `pom.xml`（改依赖属于 P1 之后的范围）。

```powershell
# 依赖 jar 落地到运行目录（cmd 命令行 8191 字符上限，不能直接塞 27 KB 的 classpath 字符串）
& 'D:/Soft/apache-maven-3.6.1/bin/mvn.cmd' -q -pl heima-leadnews-service/heima-leadnews-article `
  dependency:build-classpath "-Dmdep.outputFile=<RUN_DIR>/article-cp.txt"
# 把 jar 复制到 <RUN_DIR>/lib ，并删除 logback-classic / logback-core

# 启动（<RUN_DIR>/article-launch.cmd）
java -Xmx512m -Xms256m -XX:+UseParallelGC `
  -cp "heima-leadnews-service\heima-leadnews-article\target\classes;<RUN_DIR>\lib\*" `
  com.heima.article.ArticleApplication `
  --spring.cloud.nacos.config.enabled=false --spring.cloud.nacos.discovery.enabled=false `
  --spring.config.additional-location=file:D:/Code/Java/heima-leadnews/_optimization-artifacts/local-secrets/article-p0.yml `
  > <RUN_DIR>\article-console.log 2>&1
```

本轮实测：`Tomcat started on port(s): 51802`、`Started ArticleApplication in 13.968 seconds`。
启动日志中持续出现但**不阻塞**启动的告警：xxl-job 注册失败（admin 不可达）、
Kafka Streams / 两个 `@KafkaListener` 消费者连不上 `127.0.0.1:9092`。

## 7. 冒烟与基线脚本

- 冒烟：`GET http://127.0.0.1:51802/api/v1/article/detail/{id}`
- 负载：[p0-detail-load.ps1](../../../benchmarks/load/p0-detail-load.ps1)（闭环固定并发、逐请求断言业务码与返回 ID）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File benchmarks/load/p0-detail-load.ps1 `
  -BaseUrl http://127.0.0.1:51802 `
  -IdFile D:/Code/Java/heima-leadnews/_optimization-artifacts/20261028-P0-DATA/ids-hot.txt `
  -Concurrency 10 -WarmupSeconds 5 -DurationSeconds 30 `
  -OutDir D:/Code/Java/heima-leadnews/_optimization-artifacts/20261028-P0-RUN/runs/<run_id>
```

脚本输出 `requests.csv`（逐请求）、`summary.json`（分位/QPS/断言统计）、`resources.csv`（java 进程 CPU/内存/线程）。
退出码 0=全部断言通过，1=有断言失败，2=驱动错误。
